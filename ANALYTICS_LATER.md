# Аналитика — после появления домена

На первом запуске сайта:

- не подключать Яндекс Метрику;
- не подключать Google Analytics;
- не ставить рекламные пиксели;
- не ставить cookie для аналитики;
- не подключать внешние чаты и виджеты;
- баннер cookie не нужен, пока сайт не устанавливает cookie.

## Когда домен куплен

1. Подключить [Яндекс Вебмастер](https://webmaster.yandex.ru/).
2. Подключить [Google Search Console](https://search.google.com/search-console).
3. Метрику добавлять только по отдельному решению.
4. При добавлении Метрики сначала внедрить механизм согласия («Разрешить аналитику»).
5. Код Метрики не должен загружаться до согласия.
6. Отказ от аналитики не должен мешать работе сайта и формы.

Номер счётчика, если понадобится, вставить в `js/config.js` → `yandexMetrikaId` **только вместе** с баннером согласия.
