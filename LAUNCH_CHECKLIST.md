# Чеклист запуска сайта Анастасии Сафаровой

Дата: 3 августа 2026

## Блокеры публикации

- [ ] Указать `domain` в `js/config.js` (HTTPS-домен сайта)
- [ ] Указать `formEndpoint` в `js/config.js` — без этого форма не отправляет заявки и показывает ошибку с почтой
- [ ] Указать `publicMaxUrl` в `js/config.js` — публичная ссылка на профиль MAX
- [ ] Проверить доставку тестовой заявки на `nasti.kom@mail.ru`
- [ ] Проверить `tel:` и `mailto:` на телефоне и компьютере
- [ ] Проверить сайт на реальном телефоне (iOS/Android)
- [ ] Юридические тексты отдельно проверить специалистом по 152-ФЗ
- [ ] После публикации обновить абсолютные URL в `sitemap.xml` и `robots.txt`
- [ ] Подключить Яндекс Вебмастер / Google Search Console
- [ ] Метрику не включать без согласия на cookie

## Рекомендуется до запуска

- [ ] Получить ответы «Разрешаю»/«Согласна» по шаблону из CONSENTS.md и сохранить скрины в consents/reviews/
- [ ] Получить расширенное разрешение Анастасии на фото (consents/photos/)
- [ ] Только после этого вернуть 2–3 отзыва о психологической консультации на главную
- [ ] Прогнать Lighthouse на HTTPS
- [ ] Проверить горизонтальный скролл на ширинах 320–1440
- [ ] Проверить lightbox дипломов на телефоне
- [ ] Заменить относительные `og:image` на абсолютный URL после назначения домена

## Как подключить форму

1. Развернуть обработчик (свой backend, Formspree, Getform и т.п.), который принимает JSON POST.
2. В `js/config.js` указать:

```js
formEndpoint: "https://ваш-обработчик.example/endpoint"
```

3. Не класть секретные токены Telegram Bot API и подобные ключи в клиентский JavaScript.
4. Отправить тестовую заявку и убедиться, что письмо/уведомление доходит.

## Как добавить MAX

```js
publicMaxUrl: "https://..." // только публичный профиль Анастасии
```
